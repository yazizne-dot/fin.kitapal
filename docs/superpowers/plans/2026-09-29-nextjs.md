**Spec:** docs/superpowers/specs/2026-09-29-nextjs-design.md

## Global constraints

## Review focus
- Strict Mode double mount must not duplicate API calls/event handlers.
- Authentication failure differs from server/network failure and supports retry.
- POST/PATCH/DELETE bodies, cookies, binary downloads and origin checks survive the adapter.
- CSP permits Next hydration without making private responses cacheable.
- Build and static resources must not expose source workbooks or credentials.
