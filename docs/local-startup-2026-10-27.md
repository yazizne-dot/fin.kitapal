## TLS и запуск

Сервер предъявляет самоподписанный сертификат с DNS SAN `27645`. Node трактует такое числовое имя как IP, поэтому обычная проверка имени отвергает сертификат. Локальная конфигурация закрепляет точный SHA-256 fingerprint и SAN сертификата, полученного через существующий SSH-туннель; проверка цепочки и срока действия включена (`rejectUnauthorized: true`). Другой сертификат отвергается. При замене сертификата закрепление нужно пересмотреть.

Игнорируемые файлы `.env.pg-server.crt`, `.env.pg-tls.mjs`, `.env.backend.local` и `.env.local` подготовлены; настройки содержат секреты и не должны коммититься. Next.js направляет API-запросы на `http://127.0.0.1:3139`. Текущий frontend отвечает HTTP 200 на `http://127.0.0.1:3000/` (отдельного маршрута `/login` нет).

**Запуск API и сквозная проверка пока заблокированы:** `qarzhy_app` отсутствует, а текущая роль `fin_user` не имеет CREATEROLE.
